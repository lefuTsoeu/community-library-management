# Community Library Management System

React assignment for BIWA2110 Web Application Development.

## Requirements covered

- React JSX and reusable components
- `useState` and `useEffect`
- Lifecycle behavior through hooks
- Controlled forms, validation and submission handling
- React Router navigation
- Local Storage persistence
- Book add/update/delete
- Stock availability tracking
- Add stock and deduct/borrow stock
- Transaction history
- User login
- User add/update/delete
- Dashboard with current book availability
- Low-stock highlighting for fewer than 2 copies
- Responsive dark UI

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite address shown in the terminal.
